# EXP-20260921-016-no-barrier-multirange-coordinate-agent-protocol: Experiment Plan

目的：在已核验的无挡板坐标基线 `EXP-20260921-015` 上，检验一个确定性的虚拟多 Agent
消息链能否把杯子目标 B 的**模拟器真值相机坐标**恢复为同一个世界坐标，并仅在合同与桌面边界通过时，
把模拟状态从 A 更新为 B。B 固定为桌面内 `X,Y ∈ {-0.30,-0.15,0,0.15,0.30} m`、`Z=0.055 m`
的 25 个坐标；A 固定为 `[0.12,0,0.055] m`。本轮不放挡板，不改变机械臂关节，也不读真实相机。

角色及其唯一职责：

1. **Detection Agent（合成输入）**：从已编译场景的两台固定相机，将已知 B 从世界坐标变换为相机坐标，
   并标明 `source=simulator_truth`、相机 frame 和 scenario version。它不是视觉检测器。
2. **Coordinate Agent**：按编译相机外参逆变换为 world 坐标。
3. **Coordinator**：拒绝未知 frame、版本不一致或双相机恢复结果不一致的消息；其余消息送交下一层。
4. **Capability Agent**：仅验证带杯半径的 B 是否完整位于配置的桌面范围内；不声称可达、可抓或安全。
5. **Execution Agent（模拟状态适配器）**：只在前两层批准后，将一个内存中的 `cup_center_m` 从 A 写为 B；
   不驱动 MuJoCo actuator、不作 IK 或轨迹规划。
6. **Evidence Reviewer**：验证状态转换前后坐标，记录通过或拒绝原因。

控制项：候选模型修订、默认关节、桌面、A、相机、25 个 B 和数值不变量固定。每一个正例需要由两台
相机独立恢复同一 B；另设一条未知 frame 和一条桌外 B 的反例，二者都必须拒绝且不改写状态。
通过也只说明这个合成消息合同与 mock 状态转换在该配置下工作，不能外推为真实相机、真实抓取、执行、
可达性、碰撞或安全能力。
