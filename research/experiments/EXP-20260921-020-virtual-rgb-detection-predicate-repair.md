# EXP-20260921-020-virtual-rgb-detection-predicate-repair: Experiment Plan

019 的原始绝对 RGB 条件在人工审图中出现非杯边缘像素，所以该 run 不把“像素数为正”继续作为隔离结论。
本 run 只加两个固定的通道占优条件：`R-G≥80` 与 `B-G≥40`；其他模型、B、相机、人工颜色、帧合同与
禁用项完全冻结。对于每一张图，以四邻域计算候选 mask 的连通域；通过要求恰有一个正连通域，并保存其
像素数、包围盒和质心。

这些数字只服务于这一人工洋红虚拟金样例，不是实体相机噪声、检测质量、生产阈值或可达性标准。检测函数
仍只接收 `RgbFrame`，没有 world B、相机外参、MuJoCo model 或 data 参数。
