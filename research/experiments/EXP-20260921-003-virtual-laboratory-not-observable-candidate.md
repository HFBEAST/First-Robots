# EXP-20260921-003-virtual-laboratory-not-observable-candidate: Experiment Plan

问题：在虚拟实验室 v0 中，只把杯体从基线位置移动到桌面内的 `[-0.40, 0, 0.055]` m，是否能形成
`not_observable_by_nominal_fixed_depth`：两台固定相机均正常渲染但均无杯体标签像素？

控制项：模型、桌面、杯尺寸、默认关节、两台固定相机和渲染器固定；唯一变化为杯体位置。杯体中心
仍在桌面边缘允许范围内。通过条件包括上游/来源哈希、坐标与桌面边界、三路完整产物、两固定相机
均为零杯体标签像素。若任一固定相机仍可见，任务失败场景未形成，结果保留且不得换点重试。

该 run 不解释不可观察原因，不代表真实盲区、标定、感知、安全或控制结论。
