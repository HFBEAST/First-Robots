# EXP-20260901-002-virtual-wrist-contact-gate: Experiment Plan

问题：上一轮有 10/10 虚拟视线的静态样本，但画面显示它可能贴近或穿过模型几何。对同一 256 个
确定性关节限位样本，MuJoCo 的静态接触数为零时，腕部虚拟相机的几何可见杯数分布如何？

输入和控制项：固定 Menagerie SO-101 commit、前一 run 的半可达范围和 10 个杯位姿；使用 seed 11
的同一姿态样本；禁止所有 actuation、IK、轨迹和硬件交互。每个样本记录 `qpos`、`ncon`、腕部可见杯数。

判据：完整报告 257 个样本（含默认姿态）、零接触样本数、零接触样本中的最大可见数和第一个最大样本。
不设“安全”或“可执行”阈值；未通过接触门禁的样本也完整保留。

预期产物：不可覆盖的 formal run manifest、样本表、结果与配对 record。所有结果均为候选模型内部的
静态观测，保持 `pending_human_review`。
