但没有记录从默认配置到该样本的中间配置。在线性关节配置段的固定离散采样中，MuJoCo 接触数和
腕部虚拟相机几何可见杯数如何变化？

以及前一 run `first_maximum_zero_contact` 所指样本。对端点之间的 65 个等间隔关节配置进行
前向运动学计算；每个配置分别评估 10 个杯位，记录 `qpos`、每杯 `ncon` 和几何可见数。禁止
actuation、控制器、动力学步进、IK、轨迹优化和硬件 I/O。

判据：完整记录 65 个配置、端点索引、关节限位检查、每配置的全部接触数和可见杯数；仅以产物
完整性作为 run 通过条件。不会把零接触配置段称为安全、可执行或可到达轨迹。

局限：线性关节插值只是本 run 的离散配置扫描，不是时间参数化轨迹，未检查速度、加速度、力矩、
连续碰撞、真实碰撞模型、真实相机或真机校准。即使全部离散样本为零接触，也不能推出其间无碰撞或
任何真机能力。

预期产物：不可覆盖的 formal run manifest、完整配置段表、结果与配对 experiment record。结果
保持 `pending_human_review`。
