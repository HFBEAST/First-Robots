# EXP-20260901-001-virtual-wrist-coverage: Experiment Plan

问题：候选模型的默认腕部相机在前一 run 中为 0/10 几何可见。固定模型、虚拟杯子工作区和相机后，
是否存在**已采样**的静态关节姿态具有非零几何可见杯位姿？

方法：以 seed 11 在全部模型关节限位中采样 256 个静态 `qpos`，对每个姿态以 MuJoCo 射线检查前一
run 相同半可达范围内 10 个确定性杯位姿。无驱动、无轨迹、无 IK、无碰撞评估。报告完整覆盖计数和
第一个达到最大计数的样本；不设置成功阈值。

预期产物：不可覆盖 run manifest、姿态/覆盖 JSON、最大覆盖姿态的 RGB 画面、结果和配对 record。
这项研究不能证明真机可见性或执行可行性。
