# EXP-20260921-002-virtual-laboratory-static-observation-task: Experiment Plan

问题：虚拟实验室 v0 的冻结静态状态中，杯体是否由至少一台名义固定相机的 simulator segmentation
标签观察到？

阻塞前提：001 的结果与状态文件哈希必须匹配冻结配置并保持技术通过。唯一任务判据是至少一台
`fixed_depth_*` 相机具有一个或更多杯体标签像素；输出明确的可观察/不可观察终态及逐相机证据。
腕部相机标签不参与该任务成功条件。禁止重渲染、动作、控制、硬件 I/O 和任何感知模型。

局限：标签是仿真评价元数据，不得被未来产品运行时当作感知输入。结果只证明此冻结虚拟状态下的
任务终态，不建立真实相机、检测、可达性、安全或机器人能力结论。
