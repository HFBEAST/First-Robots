# EXP-20260916-001-virtual-wrist-projection-diagnosis: Experiment Plan

问题：`EXP-20260902-003` 中 40 个组合的几何射线命中杯体，但没有任何组合在腕部虚拟相机的
segmentation raster 中出现目标像素。对于同一 650 个配置—杯位组合，杯体中心相对候选腕部相机的
位置、透视视锥和候选渲染近远平面分别是什么？

输入和控制项：固定 Menagerie `robotstudio_so101` revision、`EXP-20260902-002` 的配置段与杯位表，
以及 `EXP-20260902-003` 的射线/raster 对照表。对每个组合执行前向运动学，记录世界坐标、相机坐标、
沿相机前向（`-Z`）深度、相机 `fovy`、投影平面边界和 `vis.map.znear/zfar × stat.extent` 候选距离。
保留所有条件：相机后方、候选深度裁剪范围外、透视视锥外、视锥内、射线结果和既有 raster 结果。
禁止渲染、感知、actuation、控制器、动力学步进、IK、轨迹优化和硬件 I/O。

判据：完整记录 650 个组合，确认两个来源表具有相同的配置索引和杯位索引，并输出每个条件的计数。
仅以完整产物作为 run 通过条件；不设任何可见性、像素或能力阈值。

局限：用杯体中心代表其投影位置，不能表示完整圆柱体的边界可见性；候选模型相机参数不等于实体腕部
RGB 相机标定。视锥/裁剪条件只能排除或保留候选解释，不能独立证明遮挡、真实不可见、感知失败、
控制可行性或安全性。

预期产物：不可覆盖的 formal run manifest、逐组合投影诊断表、结果与配对 experiment record。结果
保持 `pending_human_review`。
