# EXP-20260921-012-world-coordinate-contract-review: Experiment Plan

目的：冻结后续单步研究共用的世界坐标合同，并生成可人工审阅的完成图。世界原点是候选模型的 `baseframe`
和名义桌面顶面；+X 从机器人基座指向杯体与挡板，+Y 为桌面横向，+Z 向上。

固定变量：默认六关节 qpos、桌、杯、挡板、两台固定相机的全部世界坐标，以及两台仅作审图的虚拟相机。
三根红/绿/蓝世界轴仅辅助阅读坐标，不参与碰撞、传感、感知或任务。唯一新增内容是审图相机与可视化轴，
不改变已有物品坐标。

通过条件：来源哈希匹配；`mj_forward` 后各命名对象和 baseframe 的世界坐标、桌面顶面均精确匹配；四台
相机在配置位置编译；斜视和近俯视 RGB 图像产物存在且非单色。图像用于人工确认布局，运行通过仍保持
`pending_human_review`。

本 run 不定义侧抓末端目标，也不运行 IK、碰撞、轨迹、控制、硬件或多机器人逻辑。
