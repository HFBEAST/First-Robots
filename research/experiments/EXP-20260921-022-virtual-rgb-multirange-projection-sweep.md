# EXP-20260921-022-virtual-rgb-multirange-projection-sweep: Experiment Plan

目的：在 021 单一金样例后，只将杯中心 B 扩展到固定的 5×5 XY 网格（25 点），重复同一虚拟 RGB
component → 质心射线 → 固定中心高度平面交点流程。每点和每个相机都保存原始 RGB、mask、组件和估计值；
另外记录两相机估计差及相对 B 的评估偏差。

控制项：模型、无挡板、默认关节、桌、杯尺寸/人工色、相机、RGB 合同、颜色谓词、投影平面和渲染尺寸固定。
唯一变量是 B 的 XY 坐标。通过只要求所有已计划帧保持单组件并产生有限前方平面交点。扫掠不定义数值容许，
不融合、不向 Coordinator 发送结果，也不执行动作；它的产物只用于下一步确定虚拟融合候选规则。
