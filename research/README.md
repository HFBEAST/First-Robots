# 可选研究旁车

本目录保存可复现研究所需的实验计划、实验专用配置、种子、运行记录、报告和产物。
产品代码、运行配置、脚本和测试不得导入或读取本目录。

## 初始研究队列

1. 复现 MRBTP-demo 的最小多机器人行为树，确认共享目标与异构动作模型如何协作；
2. 复现 RoCoBench 的一个多机械臂任务，记录提示词能力描述、碰撞反馈和失败边界；
3. 复现 TAMPURA grasping notebook，确认信息动作和不确定性状态；
4. 在本项目协议稳定后，建立 SO-101 单臂主动探索和三臂接力的正式对照实验。

以上均为待执行事项，不是已完成或已采纳结论。每次正式运行必须使用独立 `experiment_id`
和不可覆盖的 run manifest；人工复核状态与技术校验分开。

删除研究旁车前，必须把已采纳结论浓缩到 `docs/decisions/`，并运行
`experiment-management verify-detachable .`。
